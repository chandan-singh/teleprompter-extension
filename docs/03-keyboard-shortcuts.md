# 03. Keyboard Shortcuts Reference

Teleprompter is engineered for complete **hands-free keyboard control**. You can control your presentation using a standard computer keyboard, a wireless presentation clicker, or foot pedals mapped to standard keys.

Press `?` or `/` while presenting to open the in-prompter shortcut cheat sheet at any time.

---

## 🎮 Playback & Navigation

| Key                        | Action                                          | Operating Mode         |
| :------------------------- | :---------------------------------------------- | :--------------------- |
| **`Space`**                | Play / Pause scrolling                          | Voice-Sync & WPM modes |
| **`Space`** or **`Enter`** | Advance to the next paragraph                   | Paragraph Mode         |
| **`↓` (Down Arrow)**       | Nudge script forward by ~3 words                | All modes              |
| **`↑` (Up Arrow)**         | Nudge script backward by ~3 words               | All modes              |
| **`→` (Right Arrow)**      | Advance to next paragraph                       | Paragraph Mode         |
| **`←` (Left Arrow)**       | Return to previous paragraph                    | Paragraph Mode         |
| **`R`**                    | Restart script from the very beginning          | All modes              |
| **`Esc`**                  | Exit prompter view and return to script library | All modes              |

---

## ⚡ Speed & Display Adjustments

| Key                | Action                       | Details                                          |
| :----------------- | :--------------------------- | :----------------------------------------------- |
| **`+`** or **`=`** | Increase speed (+10 WPM)     | Immediate smooth clock rebase                    |
| **`-`** or **`_`** | Decrease speed (-10 WPM)     | Immediate smooth clock rebase                    |
| **`]`**            | Move reading guide line down | Shifts visual reading focus lower on screen      |
| **`[`**            | Move reading guide line up   | Shifts visual reading focus higher toward webcam |

## 🎯 Presentation Clicker & Remote Compatibility

Most wireless USB/Bluetooth presentation clickers (such as Logitech Spotlight, R400, R800, Kensington, or Satechi remotes) transmit standard keyboard signals:

- **Next Slide button** typically sends `PageDown` or `Right Arrow` / `Space`.
- **Previous Slide button** typically sends `PageUp` or `Left Arrow`.
- **Blank / Black Screen button** typically sends `.` or `B`.

Teleprompter natively maps these signals:

- In **Paragraph Mode**, standard presentation clickers advance and retreat through your slides seamlessly.
- In **Voice-Sync and WPM modes**, clicking the primary remote button toggles play and pause.

---

## 💡 Pro Tips for Smooth Operation

1. **Full Screen**: Press `F11` (Windows/Linux) or `Ctrl + Cmd + F` (Mac) to put your Chrome browser into true full-screen mode, hiding browser tabs and OS docks.
2. **Hidden Controls**: The player automatically hides on-screen controls and cursor after 3 seconds of inactivity so your audience never sees navigation widgets reflected in your eyes or glasses. Simply move your mouse to bring them back.
3. **Emergency Stop**: If you lose your place or need to step away from the podium, tap `Space` to immediately freeze the prompter.
