## 📝 What Details Help Us Fix Bugs Fast?

When submitting a bug report, including the following information allows us to reproduce and fix issues much faster:

1. **Operating System**: macOS, Windows, Linux, or ChromeOS.
2. **Chrome Version**: e.g., Chrome 128 (found under `chrome://version`).
3. **Active Prompter Mode**: Voice-Sync, WPM Auto-Scroll, or Paragraph Click-Through.
4. **Speech Engine** (if using Voice-Sync): Web Speech API, Local Whisper, or Remote OpenAI-Compatible.
5. **System Diagnostics Status**: Run **System Diagnostics** in the in-app Help Center (`F1`) and mention any items marked in amber or red.
6. **Steps to Reproduce**: What you clicked or spoke right before the issue occurred.

## 🔒 Privacy & Safety Reminder

Never share private API keys, sensitive script content, or personal credentials when submitting a public bug report or issue ticket. Teleprompter stores all your data locally, and our support team will never ask for your passwords or private keys.
